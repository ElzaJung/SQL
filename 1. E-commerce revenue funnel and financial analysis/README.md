## Business Task

**Company:** An international multi-category marketplace (like Rakuten) experiencing high traffic but compressing operating margins.

**Business model:**
1. It charges a 12% take-rate commission on gross merchandise value (GMV) fulfilled by merchant partners
2. Growth relies on repeat orders and converting high-intent browser traffic into paid checkout conversions

**My role:** Product analytics manager planning service planning and proposal based on analysis results.

**Key stakeholders:**
1. **VP of Sales:** Cares about funnel drop-off, cart abandonment, and mobile/desktop session-to-purchase conversion rates.
2. **VP of Merchandising:** Cares about GMV share per category, brand power vs unbranded magin and price sensitivity.
3. **Customer Center:** Cares about Customer Acquistion Cost (CAC) payback, high-value customer retention, and 60-day Lifetime Value (LTV).

**Project Trigger:**
In Q4 2019, traffic grew 22% YoY, but overall conversion rate dropped by 38 basis points. Executive leadership suspects high cart drop-offs in consumer tech and inefficient session flows. They have budgeted $1.5M for Q1 feature engineering and merchant subsidies.

### Q1. What does our full-funnel conversion rate look like month-over-month, and where is the leak between view and purchase?

#### Step 1:
```sql
WITH metrics AS (
    SELECT 
        (SELECT COUNT(DISTINCT session_id) FROM sessions) AS total_sessions,
        (SELECT COUNT(DISTINCT transaction_id) FROM transactions) AS total_orders
)
SELECT
    total_sessions,
    total_orders,
    ROUND(100.0 * total_orders / total_sessions, 4) AS conversion_rate_pct
FROM metrics;
```

| total_sessions | total_orders | conversion_rate_pct |
| :--- | :--- | :--- |
| 80000 | 120000 | 150.0 |

Conversion rate percentage is 150%. However, this calculates event conversion, not user session conversion, skewing numbers when users refresh a product page 10 times before buying once. 

#### Step 2:
```sql
WITH total_visitors AS (
    SELECT COUNT(DISTINCT customer_id) AS total_visitors FROM sessions
),
total_buyers AS (
    SELECT COUNT(DISTINCT customer_id) AS total_buyers FROM transactions
)
SELECT 
    v.total_visitors,
    b.total_buyers,
    ROUND(100.0 * b.total_buyers / v.total_visitors, 2) AS customer_conversion_rate_pct
FROM total_visitors v, total_buyers b;
```

Customer conversion rate is 101.19%. 

| total_visitors | total_buyers | customer_conversion_rate_pct |
| :--- | :--- | :--- |
| 9824 | 9941 | 101.19 |

#### Step 3:
Customer conversion rate per month is as below.

```sql
WITH monthly_visitors AS (
    SELECT 
        strftime('%Y-%m', session_date) AS year_month,
        COUNT(DISTINCT customer_id) AS total_visitors
    FROM sessions
    GROUP BY year_month
),
monthly_buyers AS (
    SELECT 
        strftime('%Y-%m', transaction_date) AS year_month,
        COUNT(DISTINCT customer_id) AS total_buyers
    FROM transactions
    GROUP BY year_month
)
SELECT 
    v.year_month,
    v.total_visitors,
    COALESCE(b.total_buyers, 0) AS total_buyers,
    ROUND(100.0 * COALESCE(b.total_buyers, 0) / NULLIF(v.total_visitors, 0), 2) AS customer_conversion_rate_pct
FROM monthly_visitors v
LEFT JOIN monthly_buyers b ON v.year_month = b.year_month
ORDER BY v.year_month ASC;
```
